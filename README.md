# TextRPG — веб-версия

Браузерная версия текстовой RPG «Забытый лес». Открывается по ссылке на телефоне и на компьютере, ничего устанавливать не нужно.

## Ссылки

- Выбор версии: https://sadboygamesofficial.github.io/textrpg-web/
- С сохранением: https://sadboygamesofficial.github.io/textrpg-web/with-save/
- Без сохранения: https://sadboygamesofficial.github.io/textrpg-web/no-save/

## Что внутри

- `index.html` — страница выбора версии.
- `with-save/index.html` — игра с сохранением прогресса в браузере (localStorage).
- `no-save/index.html` — игра без сохранения, каждый вход начинается заново.

Каждый файл самодостаточный: стили и код внутри одного HTML, поэтому его можно просто скачать и открыть с диска.

## Правила игры

- Три класса: Воин (много защиты), Лучник (баланс), Маг (много урона, мало здоровья).
- Урон = атака минус защита, но всегда не меньше 1 — и по врагу, и по герою.
- Максимальный уровень героя и врагов — 50.
- Уровень врага подбирается случайно рядом с уровнем героя, изредка попадается заметно более сильный противник — тогда лучше сбежать.
- Здоровье не восстанавливается между боями: полное лечение даёт только возрождение после смерти.
