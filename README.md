# TextRPG — веб-версия

Браузерная текстовая RPG «Забытый лес». Открывается по ссылке на телефоне и на компьютере, устанавливать ничего не нужно.

## Ссылка

https://sadboygamesofficial.github.io/textrpg-web/

Старая ссылка `/with-save/` перенаправляет на главную. Версия без сохранения убрана: осталась одна игра, и прогресс в ней сохраняется в памяти браузера.

## Что внутри

- `index.html` — вся игра в одном файле: разметка, стили и код. Файл можно скачать и открыть с диска.
- `with-save/index.html` — страница-перенаправление для старой ссылки.

## Игра

- Три класса: Воин (много защиты), Лучник (баланс), Маг (много урона, мало здоровья). Прогресс хранится отдельно для каждого класса.
- Бой: атака, побег, пауза с информацией о персонаже, разбор урона.
- Уровни до 50-го, очко навыка за уровень, урон всегда не меньше 1 — и по врагу, и по герою.
- Уровень противника подбирается случайно рядом с вашим: изредка попадается заметно сильнее (игра предупреждает — лучше сбежать), изредка слабее. Чем выше ваш уровень, тем реже встречается слабая добыча.
- Здоровье между боями не восстанавливается: полное лечение даёт только возрождение после смерти.
- Главное меню → «Настройки» → «Очистить прогресс» спрашивает «Вы уверены, что хотите удалить всё безвозвратно?» — «Да» стирает все сохранения этой игры в браузере, «Нет» возвращает в настройки.
