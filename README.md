# TextRPG

Браузерная текстовая RPG «Забытый лес». Ничего устанавливать не нужно.

## Играть

https://sadboygamesofficial.github.io/textrpg-web/

Ссылка одна и та же после обновлений. Прогресс хранится в браузере на вашем устройстве и при выходе новой версии не пропадает.

Старая ссылка `/with-save/` перенаправляет сюда.
